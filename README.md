### 🚀 Project Overview (English)
This system was designed to handle the core logistics of a delivery company. It features a robust multi-layer architecture that separates business logic from data access and user interface.

**Key Features:**
- **Data Persistence:** Full integration with SQL databases for reliable data storage.
- **Client Management:** Logic for ID validation (cedula) and automatic link between clients and multiple addresses.
- **Package Tracking:** System to register and categorize packages (Weight, dimensions, status).
- **GUI (Java Swing):** User-friendly interface for searching and registering records.
- **JPA/Hibernate Ready:** Includes entity mapping for Alumno/Student records using JPA annotations.

**Technical Stack:**
- **Language:** Java 8+
- **Database:** SQL (via JDBC)
- **Frameworks:** Java Swing (UI), JPA/Hibernate (ORM)
- **Architecture:** Layered Architecture (Logic, Data, Presentation, Classes).

### 📦 Resumen del Proyecto (Español)
Este sistema fue diseñado para gestionar las operaciones centrales de una empresa de logística. Presenta una arquitectura robusta de múltiples capas que separa la lógica de negocio del acceso a datos y la interfaz de usuario.

**Funcionalidades Clave:**
- **Persistencia de Datos:** Integración completa con bases de datos SQL para almacenamiento fiable.
- **Gestión de Clientes:** Lógica de validación de cédula y vinculación automática entre clientes y múltiples direcciones.
- **Control de Paquetes:** Registro detallado de paquetes (Peso, dimensiones, descripción y estado).
- **Interfaz Gráfica (Swing):** Formularios intuitivos para la búsqueda y registro de información.
- **Persistencia Avanzada:** Implementación de entidades con anotaciones JPA para el manejo de objetos persistentes.

**Stack Técnico:**
- **Lenguaje:** Java 8+
- **Base de Datos:** SQL (vía JDBC)
- **Frameworks:** Java Swing, JPA/Hibernate.
- **Arquitectura:** Arquitectura por capas (Lógica, Base de Datos, Presentación, Clases).
